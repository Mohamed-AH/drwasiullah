# دليل تسليم الملفات الصوتية للدروس المرئية

**الغرض:** إضافة نسخة صوتية («استماع فقط») لكل درس مرئي في موقع **drwasiullah.com**، ليتمكّن الطلاب من الاستماع
بجودة جيدة وبأقل استهلاك للإنترنت. الملفات المرسلة تُنشر على الموقع بإذن الشيخ حفظه الله.

## 1. ما المطلوب؟
ملف صوتي **واحد لكل درس** — وهو الدرس نفسه المنشور على يوتيوب. القائمة الكاملة (944 درسًا) في الملف
`lessons-needing-audio.csv` (يُفتح بالإكسل).

## 2. الصيغة والجودة
- **أي صيغة شائعة تصلح:** MP3، M4A/AAC، WAV، FLAC، OGG.
- أرسلوا **الملف الأصلي بأعلى جودة متاحة**، ولا تعيدوا ضغطه ولا تغيّروا مستوى صوته؛ نحن نوحّد الصيغة والجودة
  ومستوى الصوت آليًا لجميع الدروس.
- مقطع واحد كامل لكل درس (لا تقسيم إلى أجزاء، ولا دمج دروس).

## 3. تسمية الملفات (الأهم)
اسم الملف = **معرّف فيديو يوتيوب** (11 حرفًا بعد `v=` في رابط الفيديو):

| رابط الفيديو | اسم الملف |
|---|---|
| `https://www.youtube.com/watch?v=BHlv9TkmsME` | `BHlv9TkmsME.mp3` |

بهذا يرتبط كل ملف بدرسه تلقائيًا دون أخطاء. إن تعذّر ذلك فسمّوا الملفات كما تشاؤون **وأرفقوا ملف
`mapping.csv`** بعمودين: `file` و `youtube_url`، أو املؤوا العمود الأخير في `lessons-needing-audio.csv`.

## 4. طريقة الإرسال
- **رابط تحميل مشترك** (Google Drive أو OneDrive أو Mega أو WeTransfer)، **على دفعات** — الأفضل دفعة لكل سلسلة.
- مجلد لكل سلسلة اختياري ومفيد؛ ولا حاجة لضغط الملفات (ZIP) إلا لتسهيل الرفع.
- **الأولوية المقترحة:** شرح صحيح مسلم، ثم شرح سنن ابن ماجه، ثم فضائل الصحابة، ثم باقي السلاسل.

## 5. الدروس الجديدة
بالطريقة نفسها بعد نشر كل درس (أسبوعيًا أو عند توفّر الملفات).

## 6. إقرار مطلوب (مرة واحدة)
رسالة مكتوبة (واتساب أو بريد) تفيد بأن الشيخ/الفريق يأذن بنشر هذه الملفات الصوتية على الموقع.

## ماذا سنفعل نحن؟
توحيد الصيغة (أحادي القناة، AAC 48 kbps) وضبط مستوى الصوت، ثم الرفع وربط كل ملف بدرسه، وإرسال تقرير بأي ملف لم
يتطابق مع درس، وبالدروس التي ما زالت بلا نسخة صوتية.

---
### For the developer (English)
Files are matched by YouTube video ID in the filename (or `mapping.csv`); `tools/ingest_audio.py` (to be built when
the first batch arrives) normalises to mono / −16 LUFS / AAC-LC 48 kbps / `+faststart`, tags, uploads, and sets `audio` +
`duration` on the lesson. See `ROADMAP.md` Phase 4.
